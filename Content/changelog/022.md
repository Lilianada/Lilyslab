# Terminal Notes & Firebase Migration

## New Features

### 🖥️ Terminal Notes
- Added a new Terminal Notes project to the playground
- Simple, minimal note-taking interface with terminal aesthetics
- Hybrid storage: loads initial content from server, saves changes to localStorage
- Auto-saves every 15 seconds to localStorage
- Manual save with Ctrl/Cmd + S keyboard shortcut
- Character and line count statistics
- Monospace font for clean, readable text
- Added to playground page and sidebar navigation

## Infrastructure Updates

### 🔧 Firebase Migration
- **Migrated all user-generated content to Firebase Firestore** 
- Fixes production deployment issues where file system writes were failing
- APIs now use Firestore instead of local file storage:
  - **Guestbook entries** → `guestbook` collection
  - **Ask Me Anything questions** → `ama-questions` collection  
  - **Micro-blog posts** → `micro-blog` collection
  - **Tool submissions** → `tool-submissions` collection
- Improved data persistence and scalability
- No more "Error failed to save entry" messages in production

## Bug Fixes

### 🐛 Content Security Policy
- Updated CSP headers to properly allow Google Fonts
- Fixed font loading issues with external stylesheets
- Improved CSP formatting and wildcard domain support

## Technical Details

- Accessible keyboard shortcuts
