# Wants — 100 Things I Want To Do

## New Features

### ✅ New `Wants To Do` page
- Added a new personal page listing things to do (and that have been done) in the `/me` section.
- Route: `(with-sidebar)/me/wants-to-do` — file: `app/(with-sidebar)/(me)/wants-to-do/page.tsx`
- Displays a simple checklist UI with completion state and a compact progress indicator.
- Initial items added include learning goals, travel plans, and gear wishes (20 items).

## Technical Notes
- Implemented as a client component to allow interactive completion state.
- Reuses site `ScrollProgress` and `Footer` components for consistent layout and behavior.
- Added the list as an inline array in the page component; can be migrated to a data file or CMS later.
