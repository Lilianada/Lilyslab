I now write everyday and you can too...

Here's how building my personal Notes App made me write everyday.

I enjoy jotting down things and because I want to write more, I built an app for myself that would encourage me to do this. Writing was a bit stressful before because I had to open my *Apple Notes app* to draft and Notion to edit. 

But now, I can draft and edit from one platform and all from my chrome browser as the browser is the one app that I cannot go a day without using, it is always open on my mac. 

I also now have the ability of adding as many necessary features that'll help me write better.


**My notes app is pretty basic:** \
→ create notes, \
→ write in markdown, \
→ view rich-text, \
→ change fonts. 
 

**Some features I will be adding in the next update:** \
✓ Total word count \
✓ Categories using color-coding \
✓Adding 'date created' and 'last updated' \
✓ Keep writing streaks (maybe)

I've been having a field day with building tools that would help make everyday life easy for me.
