You don’t need another tutorial, you don’t need another article. You need to start writing code. Start from where you are. 

I learnt how to write code from actually writing code. I was constantly coming up with new app ideas and shooting myself in the leg trying to build them. So I learnt from doing, not reading more or watching more but actually writing more.

You’ll hit roadblocks and get stuck. Unblocking yourself might require you to get help from videos and articles, that’s okay.  In fact, that’s the best time to watch or read anything because you learn better from your mistakes.

In programming, you learn from doing not learning “to do”. That doesn’t mean you shouldn’t understand basic concepts, best practices or principles. You learn to build a todo list app from building a todo list app.
