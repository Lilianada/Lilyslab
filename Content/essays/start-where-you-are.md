I've spent the last 3 months reading and writing short essays for myself. I have done a lot of introspection on how to be a better creative. 

How to put out more quality content and each time I think of this, what comes to mind is "buy a new phone to shoot better videos", "buy a new macbook to build better products", "you need a new book and set of pen to plan better" "create a new instagram page to post a different type of content", "buy an ipad to create better content". 

I became heavily overwhelmed by the number of new things I thought I needed in order to be able to start all the things I wanted to do.

Then, I came across a few notes, one of which said to make things with the time, space and materials you have present. Another said, "start where you are".

We always feel the grass is greener on the other side. What if it isn't?

Start with as little as possible, stay consistent enough. Make it easy to quit without regrets. We always want to start big, grande! We build a website for our new business when we haven't had one customer yet. We buy expensive cameras and gadgets to create content without knowing the type of content we want to create or without an already existing fanbase requesting for better quality (this "we" is actually me).

What happens when a few weeks down the line you discover this new thing isn't for you? All the resources you put into it becomes a waste. All the time you put preparing or planning becomes time wasted.

Starting where you are makes it easy for you to get feedback early and either quit and move to the next thing or improve on what you have.
