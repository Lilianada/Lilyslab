Coding doesn't have to be complicated or technical. Like picking up a new hobby, you can treat it like a new experiment that's worth exploring. And why not? At the end of the day, you'd have learnt three new languages and gotten yourself a blog or [[digital garden]].

If you're reading this and have any interest at all in owning your own website hand-built by you, then you're in the right place. This isn't a tutorial. It's more of a push, an encouragement and an easy guide to get you into writing code.

### Just Write Code

In programming, you learn by doing, not learning “to do”. You learn to build a todo list app from building a todo list app. That doesn’t mean you shouldn’t understand basic concepts, fundamentals, best practices or principles. 

You don’t need another tutorial; you don’t need another article. You just need to start writing code. 

I learnt how to write code from actually writing code. I was constantly coming up with new app ideas and shooting myself in the foot trying to build them. So I learnt from doing, not reading more or watching more but actually writing more.

As a beginner, do not approach writing code from the standpoint of being a software engineer; instead see it as simply writing instructions that your computer can understand and execute.

### Write Code, Have Fun

The best approaches to writing code are:

- **Understanding the project, problem or end goal:** If your goal is to build a simple personal website or blog, then you have a clear goal. You'll need to think about the number of pages you want to have, what each page would likely be and then you can start figuring out what it'll take to build out each page. Do not spend too much time tinkering on this. To help you move forward, always  remember that your goal is to write code and not to design an amazing UI. Your code is never a body of finished a work. There's always time to go back and improve on it, so focus on the technicalities and leave the designing for later.
- **Start with basic languages:** When you want to start something as technical as programming, pick the easy languages to give you a soft landing. Don't go choosing languages that are old or complicated. You also don't need to learn everything all at once. My goal is to get you to learn HTML, CSS and JavaScript. I would advise starting with HTML, build a few applications with just HTML before picking up CSS or even JS. Make sure you understand the fundamentals of these languages before picking up any framework.
- **Build small projects:** Learning comes from doing. Start and complete several small projects. Sometimes we get the sense of doing from watching tutorials but what happens after the tutorial is over? Build on your own. Own your mistakes and research ways to fix them. 
- **Stay consistent with learning:** You have to show up consistently. Thirty minutes each day can make a better impact than a couple of hours once a week. Progress will be slow but it compounds over time. 
- **Always ask for help:** You’ll hit roadblocks and get stuck. Unblocking yourself might require you to get help from documentation, videos and articles; that’s okay.  In fact, that’s the best time to watch or read anything because you learn better from your mistakes. You can also join a community, find an accountability partner or get a mentor. Surrounding yourself with people or having someone who understands your struggles and is willing to help makes the journey easier.

My goal here is to get you to own your own website. With this in mind, rest assured that the journey won't be too difficult. It might challenge you, but fear not, with a little persistence, you'll overcome. I have prepared a simple guide to get you from novice to website owner. You can access it via the [resources](/resources) page.

Learning to write code can be difficult, but the difficulty depends on what your end goal is. Software engineer or simple personal website? HTML or Java?

You can learn to write code without studying computer science in depth. You can make little websites without understanding software architecture. You can experiment with JavaScript without worrying about becoming a professional developer.

You can simply enjoy making things with code.
