# I Now Write Everyday 

How building my personal Notes App made me write everyday.

I enjoy jotting down things and because I want to write more, I built an app for myself that would encourage me to do this. Writing was a bit stressful before because I had to open my *Apple Notes app* to draft and *Notion* to edit. But now, I can draft and edit from one platform and all from my chrome browser as this is the one app that I cannot go a day without using, it is always open on my mac. 

I also now have the ability of adding as many necessary features that'll help me write better.

My notes app is pretty basic → create notes, write in markdown, view rich-text, change font.
