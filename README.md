# Lily's Space

A modern, personal portfolio and blog website where I share my experiences, thoughts, and work. Built with Next.js, Tailwind CSS, and powered by Obsidian databases.


## About

This is my personal digital space where I share:
- Work experience and projects
- Technical writing and insights
- App dissection case studies
- Curated resources and tools
- Interactive Q&A through Ask Me Anything (AMA)
