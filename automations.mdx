# Lilyslab Automation Commands

## Content Creation

```bash
# Create a new log
npm run create:log "Project Title" "#tag1,#tag2,#tag3"

# Create a new note
npm run create:note "Note Title" "tag1,tag2,tag3"

# Create a new writing
npm run create:writing "Article Title" "tag1,tag2,tag3"

# Create a new bookmark
npm run create:bookmark "Resource Title" "tag1,tag2,tag3"
```

## Content Metadata

```bash
# Update reading time and word count for all content
npm run update:metadata
```

## Content Relationships

```bash
# Generate backlinks between related content
npm run generate:backlinks
```

## Image Optimization

```bash
# Optimize images in content folders
npm run optimize:images
```

## Link Validation

```bash
# Check for broken internal and external links
npm run check:links
```

## Social Sharing

```bash
# Generate OG images for social sharing
npm run generate:og
```
